# 从对话保存 Simulink 模型与验证仿真

## 一次保存成功、仿真未运行的会话

用户上传了一个 NumPy 状态转移函数，并要求生成可在 Simulink 运行的同一对象模型。建模工具返回了模型结构和端口连线检查结果。接下来的单次 MATLAB 调用先保存，随后试图设置输入，最后才调用仿真。

| 可核对的记录 | 工程结论 |
|---|---|
| 调用使用模型名保存。后来在项目根目录找到了 SLX，复制入会话工作区后两个文件的 SHA-256 相同。 | 保存已经成功，首次落盘位置在用户要求的会话工作区之外。 |
| 对根级 Inport 设置 `Value` 时，MATLAB 明确返回该块缺少这个参数。 | 调用在输入设置处中断，本次 `sim` 没有执行。 |
| 旧资源管理器收到工具错误后隔离了共享会话，随后多次工具请求均在派发前被拒绝。 | 日志能确认工具请求受阻。判断 MATLAB 进程是否退出还需要独立的进程记录。 |
| 查找模型的部分 PowerShell 作业在设置工作区 ACL 时发生访问拒绝。其后工作区内写入了脚本和说明。 | 文件查询受沙箱权限阻塞与 Simulink 参数错误是两个故障。交付 SLX 还需要核对模型文件本身。 |

结构检查覆盖未连接端口、未连接线和 Stateflow lint。保存的模型仍将位移送入阻尼支路，位置与速度输出接反，逆质量增益只作用在输入力上。按该例的物理方程，应先求输入力与弹簧力、阻尼力的合力，再除以质量。加速度第一次积分得到速度，第二次积分得到位移。后续用户改用 Python 生成训练数据并拟合网络，SLX 与原对象的数值一致性仍待验证。

## 操作与验收

1. 在目标工作区打开工程对话，创建或编辑模型，核对模型参数来源、根级端口次序和物理方程。多个对话可能共用同一个 MATLAB。若 `new_system` 提示同名模型已加载，先核对它的来源。尚未保存的内存模型没有文件路径可用于判断归属，来源不明时请换名新建，再保存本次成功创建的模型。需要独立运行的模型，应使它在新会话中也能取得打开或仿真所需的参数。
2. 调用 `control_save_simulink_model`，例如传入 `{"model":"MassSpringDamper"}`。成功响应中的 `path` 是会话工作区内 SLX 的实际绝对路径，`simulation` 此时为 `not_run`。如遇同名无关文件或模型已绑定其他目录，应保留原文件并明确选择副本或新模型名，避免覆盖其他任务的模型。
3. 单独准备仿真。根级 Inport 的激励可用外部 Dataset 定义，并通过 `Simulink.SimulationInput.setExternalInput` 传入。若原对象使用零阶保持，输入波形也应按相同保持约定提供。用相同的状态初值、参数和采样点比较原对象与 SLX 的输出，报告时间范围、单位和偏差。
4. 输入配置出错时保留保存结果。对已识别的同步块参数错误，纠正参数后只重试失败的操作。取消、超时或终态无法确认时保留隔离，按专用会话恢复流程处理。[专用 MATLAB 连接与恢复](matlab-existing-session.md)

## 复跑原生工具回归

先用项目的专用 MATLAB 启动器创建一个仅供回归使用的会话，将其会话目录设为 `test-output/matlab-inport-<名称>/session`。看到就绪标记后，在项目根目录运行以下命令，并将示例目录替换为实际测试目录。

```powershell
node scripts/smoke-matlab-inport-save.mjs test-output/matlab-inport-demo --prepare-workspace
```

测试为该进程使用独立资源锁和新的会话工作区，经原生 Harness 工具执行器连接真实 MATLAB。选项 `--prepare-workspace` 只为本次新建的测试叶目录准备 Windows ACL。测试先保存 Inport 直通模型，再触发 `Value` 参数错误并读取资源终态。随后从返回的绝对路径重载 SLX，用常值 2 的 Dataset 独立仿真一秒，要求输出为 2 且队列为空。

同一脚本在默认 Discrete State-Space 块上单独写入两状态的 A，复现 R2024b 报 B 无效的诊断。专用会话身份与空闲状态复核通过后，脚本调用 `control_configure_simulink_plant` 一次写入并核对 A、B、C、D、初态和采样周期。

接线回归在已有部分连线的模型上故意请求不存在的 `Plant/2`，检查原始错误、专用会话的终态证明和资源状态。纠正时调用 `control_wire_simulink`，将控制量和扰动分别送进两输入 Mux，再从 Mux 接入 `Plant/1`。整批端口预检失败须新增零条线，目标已有其他来源时须保留原线。重复提交正确拓扑须新增零条线。保存后按回执的绝对路径重新加载，仿真一步，结果须与离散方程一致。各步记录见生成目录内的 `smoke-evidence.json`。验收结束后关闭这次启动的专用测试 MATLAB。

在网页验收时，用自然语言指定两路独立标量信号和一个两输入分量的离散对象，要求继续已有部分连线，保存到当前会话工作区并运行短仿真。展开工具记录，核对 Plant 配置回执中的物理端口数和所需信号宽度，以及接线回执中每条线的源、目标和保留或新建状态。接线回执的信号宽度为 `[]` 表示当前没有可用的已编译宽度；图更新与仿真负责验证实际信号维度。最后从页面给出的绝对路径重新打开文件，确认控制量与扰动按约定顺序进入 Mux，检查重载后仿真的输出。记录模型文件和仿真各自的结果。

如果在建模之后、保存之前遇到预检失败，该测试模型可能仍在专用 MATLAB 中打开。修复预检并重跑前，请先检查该测试进程内的未保存模型。MATLAB 生成的 `.autosave` 文件与工具收据中的交付路径分别核对。
