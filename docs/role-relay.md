# 原生角色、产物接力与报告

外部 bundle 声明三个原生 Harness 预设：`control-model`、`control-controller`、`control-lightweight`。Web 创建会话时传入对应 agentPreset。预设通过 scoped systemPrompt 提供角色流程，通过原生 tools.restrict 隐藏其他两个角色的专业工具，保留当前角色、工作流、帮助和通用文件/作业工具。权限仍由原生 Session 沙箱和工具执行机制处理。

旧浏览器草稿会话首次提交新任务时迁入新的角色会话。旧 ID 保留在“查看会话任务”中，原对话及任务历史可继续读取和显式恢复。草稿只保存界面状态，原生作业和工作区记录才是执行证据。

模型先调用 `control_help({operation})` 读取输入 schema、配置、前置条件和示例，然后调用对应 `control_model/controller/lightweight`。返回 jobId 只表示作业已接收，需要使用原生作业工具读取最终结果。`/control-help` 为同一目录的人机命令入口。真实对话需要在 Harness 设置中配置可用的 DeepSeek 官方 API 凭据；确定性表单无需调用模型服务。

`prepare_handoff` 校验选中产物和完整依赖链：校正/辨识模型交给控制器，控制器交给专家采集，专家数据交给模仿，模仿策略交给物理优化，转移数据交给残差训练。预测模型、评价模型、专家控制器都从确切依赖读取；不会用工作区另一个 active 模型代替。实测数据没有绑定仿真评价模型时，返回缺失输入；工况仍由用户设置。

Web 显示接力输入和缺失项，点击“采用配置并切换”后填入目标角色草稿，不立即执行。执行阶段仍重新校验依赖、单位、维度、版本和独立工况。

`inspect_artifact` 返回经过校验的有界报告预览：长轨迹最多240点、训练日志500行、同类工况24组。抽样保留端点并明确标注，指标保留原报告值，不从抽样曲线重新计算。超过预览预算时提示从工作目录读取完整报告。

`read_artifact_file` 只允许选取该产物哈希清单中的文件；文本最多32000字符，NPZ仅返回数值数组的形状/类型/范围摘要，禁用 pickle 并限制解压预览预算。二进制模型显示路径、大小、SHA-256。文件预览不执行源码。

Web 使用真实报告绘制残差误差表、训练验证曲线、GA候选评分，以及独立测试工况的输出/控制曲线。优化策略可在同一工况比较专家、模仿与优化结果，耗时、RMSE、总变差与启用的约束检查均来自报告。

实际原生会话及依赖接力的验证命令：

```powershell
node scripts/smoke-role-handoff.mjs
```

证据保存于 `docs/harness-role-handoff-evidence.json`。此脚本需要本机 Web 服务运行且日志保存在 `harness-web.log`，不调用模型 API；脚本明确读取指定非线性示例工作区，不按时间猜测最新产物。
