# 单个对象模型与确认后的采样

材料通过路径或原生上传后统一 `register_material`，再用 `register_plant` 声明适配器。登记只验证声明、文件版本和接口，不执行上传源码，不证明物理准确性。材料包括依赖文件；`source_file` 从材料产物根目录开始，例如 `source/plant.py`。

支持的入口是普通 NumPy Python 函数/显式工厂、MATLAB 函数以及声明了端口与状态映射的 Simulink 模型。原有 Torch 模型也可直接采样。普通函数为 `f(x,u,d,dt,parameters)`；`x/u/d` 是按接口顺序排列的向量。`C` 或 `g(x,parameters)` 明确给出仅依赖状态的输出。连续导数必须声明单位、Euler/RK4、子步数和零阶保持；不能把导数误作下一状态。隐藏动态记忆必须并入状态或提供受支持的薄适配器。任意工程的零适配、直接馈通和自动可微转换不在此接口承诺之内。

本阶段 SLX 自动采样限定为平坦的已知内置标量模块、完整声明的 Unit Delay 状态和固定离散步长。静态依赖图在声明状态处切断，拒绝输出直接馈通、隐藏状态、层次/不透明模块和模型回调；复杂工程仍可用原生 Toolkit 读取和编辑，但进入此批采接口需要受支持的薄数值适配器。MATLAB 函数及其绑定依赖也使用明确的纯数值子集，并对运行中的同输入结果做一致性检查；这些检查不能充当任意源程序的形式证明。

`recommend_sampling` 从声明边界提出完整候选，并不证明激励充分或推断出未知的物理意义。普通模式审阅候选，专家模式编辑同一份采样配置。支持阶跃、扫频、有界随机和显式用户时序。确定性程序在执行源代码前展开全部轨迹，检查 dt、时长、初值、幅值、每秒变化率和线性耦合约束。命令变化率包含初始命令到第一点的变化，不自动转换单位或截断越界值。

单次展开有 5,000,000 逻辑标量的内存预算，在创建大量条件或数组前拒绝超额请求；大采样任务可明确分批执行。这不限制整个项目的运行时长或批次数。

`sample_model` 输入一个 `model`，配置包含 `sampling`、可选的 `trial:{trajectories,steps}` 和 `sampling_run:'trial'|'full'`。trial 为完整计划的固定前缀，随机和扫频都不重新生成。信号与采样摘要同时覆盖完整计划和试跑范围；仅切换 `sampling_run` 重用原确认版本，变更试跑范围或任意实际参数则失效。原生签名回执仍绑定每次精确执行请求。完整训练数据至少五条独立轨迹；短试跑发布独立的 `sampling_trial`，不假造训练/验证/测试划分。

Python 与 MATLAB 函数逐步检测状态和输出的边界、有限性及适配器状态一致性，首次失败不记录违规行、不启动后续轨迹。Simulink 使用 `SimulationInput` 对每条轨迹执行有界时长仿真，在该轨迹返回后检查记录并停止后续轨迹；报告明确标记 `post_trajectory_validation`，不声称积分点上的实时保护。无法确认外部计算已停止的取消或超时仍按 MATLAB 共享资源规则隔离会话。原始模型文件不被修改。

MATLAB 采样由同一个原生作业完成：沙箱 Python 验证并生成交换清单 → 一次原生 MCP 调用运行本地可信批处理 → 沙箱 Python 核验结果和发布产物。清单及结果绑定请求 SHA、一次性 nonce、计划/适配器哈希和模型/材料版本。没有 Engine API 依赖，不逐采样点调用 MCP 或大模型。必须配置专用 MATLAB 会话与共享资源锁；纯 Python 部署省略该可选连接。

产物保存 `transitions.npz`（x、u、d、next_x、y、next_y、trajectory_id、time）、完整采样计划、适配器说明、来源及覆盖报告，完整数据按轨迹分组划分。数据来源为模拟对象，不能称为实车测量。失败/取消的合法前缀和原因保存在工作区 `failed/<stage_id>/`，不发布可用数据集。
