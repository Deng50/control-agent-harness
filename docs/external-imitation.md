# 外部专家模仿与原对象比较

这条路线复用原生 Harness 的 Session、工具、作业和取消机制，领域插件执行实际数值计算。外部专家或记录数据不需要先重新设计一个内部 MPC。

## 训练与独立交付

`train_external_imitation` 输入一个已验证的 `external_expert_dataset`。`config.network` 指定实际 MLP 的隐藏层宽、激活、学习率、batch、epochs、早停和种子；`input_dim`、`output_dim` 可显式声明，但必须与 DataInterface 一致。信号和训练摘要分别确认。已有同版本确认可复用，配置 JSON 的确认标志没有授权作用。

使用数据原有整轨/时间划分和训练集 Scaler，复用共享监督训练与检查点。验证集选择权重；最终测试预测只计算一次，外层直接读取该结果。报告保留原始网络动作、实际幅值/变化率投影后的动作、原始越界比例及投影修改行数。`max_test_action_nrmse` 和 `action_metric_scale` 属于外层配置；固定尺度必须为正，默认尺度只来自训练集。门限未请求时明确标记，未达标的候选保留为 rejected，不替换有效策略。

输出 `external_imitation_policy` 的 `bundle/` 包含权重、Scaler、输入/输出顺序、动作约束、来源、独立 Python 推理程序和依赖说明。支持的当前信号物理映射还可导出数值 MATLAB 函数。部署调用必须提供实际可获得的有序特征；变化率约束使用实际上一动作。历史窗口可以作为显式平铺输入训练，推理调用方须按相同因果规则组装，包不会补造历史、状态估计器或未来驱动。

旧内置专家数据仍使用 `train_imitation`。其独立包保留原 MLP/RNN/LSTM 数值代码；旧 RNN/LSTM 的输入是已声明常值的未来扰动预览，不等于历史序列编码。独立推理检查形状、有限值、实际上一动作和单调用内存边界。

## 原对象自主比较

先调用只读 `prepare_imitation_evaluation`，它不加载网络、不执行用户源码。准备结果从选定策略的数据祖先解析原专家、原对象和原验证/测试工况，输出具体 `config_suggestions` 和来源版本。检查并确认该配置后调用 `evaluate_external_imitation`；原生入口要求非空显式 scenarios，不能让空配置默认批准一批尚未展示的仿真。

专家与 NN 分别从相同初态运行原对象，并使用各自的反馈状态和上一实际动作。报告与记录数据上的 teacher-forced 预测误差分开，保存两条完整轨迹、跟踪误差、动作及变化率、约束失败和性能退化。训练工况的物理前缀不能通过重命名或改变时长冒充独立工况。比较不会再训练、选权重或替换策略；有限仿真不构成稳定性证明。

只有记录数据、没有可执行的原专家/对象时，准备结果为 `not_applicable`，保留离线训练报告和独立包。缺少自主历史组装器或不受支持的混合后端也给出明确原因。

## 运行时间与恢复

控制器计时固定 CPU 单线程、batch=1、预热次数和重复次数，保存硬件、库版本、实际线程池、全部计时样本和统计。Python 路线单独记录对象 reset/step/output 时间。MATLAB 路线通过一个原生 MCP 业务批次在本地执行两条闭环和控制器计时；整个守护闭环批次耗时单列，纯对象时间尚未单独计时时如实标记，不能把它算进控制器加速比。安装 MCP 或工具可见不等于完成真实基准。

外层策略包装本身没有优化器检查点。中断恢复使用实际内层 `supervised_model/supervised_training` 的权重、Adam、RNG、日志及数据/配置签名；原生恢复产生新作业。OS 确认原工作进程已退出后才可回收未发布检查点。只模仿任务在交付后结束，PGAC 是用户另行选择的后续分支。

本轮实际门禁、失败历史和数值证据以 `docs/acceptance.md` 指向的阶段归档为准；本文描述接口合同，不代替执行验收。
