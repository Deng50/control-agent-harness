# 跟踪 RMSE 优先的弹簧与电机闭环验收

本案例对两个对象沿用上一版的可执行原对象、MPC 专家、真实模仿基线和动作投影。工程任务改为优先降低位移或转速的物理 RMSE，同时限制动作幅值成本、动作增量成本和硬约束违例。

## 上一版的逐轮、逐工况诊断

弹簧原预测验证 J 从第 0 轮 0.002354365 降至第 1 轮 0.002231302，第 9 轮 0.002228976 最优，第 16 轮 0.002231370。原盲测中，权重更新带来的加权跟踪平方项变化为 −0.000009327，动作项 −0.000191197，动作增量项 −0.000001629，三项之和为 J 的变化 −0.000202154。动作项贡献了下降量的 94.6%。

原 J 对每个工况的跟踪误差先平方、归一化并求均值。报告的跟踪 RMSE 则先在各工况内开方，再等权平均。这两个统计量可以反向变化。弹簧正、负阶跃的 RMSE 分别上升 21.10% 和 62.96%，跨零反转下降 3.48%，中途接管上升 3.99%。因此原 J 降低 6.02% 的同时，按照工况等权汇总的 RMSE 升高 5.68%。

电机原训练没有停滞。预测验证 J 从第 0 轮 0.009254534 降至第 16 轮 0.009095758，固定探针上动作的最大绝对变化达到 3.085 V。原盲测跟踪平方项减少 0.000159254，动作与增量项却分别增加 0.000167505 和 0.000014161，净结果为 J 增加 0.000022412。正、负阶跃 RMSE 分别退化 5.33% 和 6.20%，跨零与中途接管分别改善 7.26% 和 5.75%，平均 RMSE 小幅改善 1.16%。两个对象原来的 3,072 个采样起点均只有 125 个处于反转阶段，没有近状态边界起点。样本分布说明应单列瞬态覆盖；目标分量和闭环轨迹给出了上述损益的直接证据。[逐轮数据、工况分解及原始日志哈希](prior-diagnosis.json)

## 预注册与数据隔离

主指标是单输出物理 RMSE 的逐工况等权均值。验证与盲测分别要求相对同分区模仿基线至少改善 1%，任何一条工况最多退化 5%。两项动作预算分别限制等权动作 RMS 增幅最多 15%，每拍动作增量 RMS 增幅最多 25%。硬约束要求状态、输出、动作和变化率均无越界。保留旧 q/r/s 算出的 J 作为诊断。两种设计分别采用 24 步与 36 步预测和预先声明的学习率，均使用 18 轮、216 次 Adam 更新、2,640 个原对象学生控制步以及 0 次新增 MPC 调用。[预注册协议](protocol.json)

每个对象新生成 12 条学生采集工况、12 条选优工况及 24 条原对象盲测工况，每条 44 拍。生成时对新旧专家与学生训练、原验证和旧盲测的物理前缀检查隔离。六族为正阶跃、负阶跃、双向跨零、中途接管、近状态限值回收和大上一动作接管；盲测每族 4 条，使用配对的干净/带噪观测。近状态工况从状态限幅的 84%–91% 附近起步，动作接管从执行器幅值的 90%–96% 起步。每个对象只使用一个训练种子。

旧专家采集和模仿阶段在新工作区重新执行，两例模仿权重张量 SHA-256 与旧基准完全一致。两个优化设计都从该权重出发。在一轮模型验证内以动作预算、最差工况与硬约束筛选，对通过的权重按物理 RMSE 排序。两个对象的训练配置、候选权重和只读历史参照哈希同时冻结后才运行原对象评价。历史参照使用上版在线候选，电机上该候选当时未获发布。新验收分别让 MPC、模仿和所选候选在同一原对象自主闭环，旧参照在相同原对象、噪声及参考上独立回放。[完整结果及冻结记录](results.json)

## 两个原对象的全新盲测

两个对象在开发验证中都选了 24 步预测。弹簧选中第 18 轮，电机选中第 1 轮。电机训练的后续轮次在开发集上还能降低 RMSE，但动作 RMS 超过了预设预算。两种候选设计加总，每个对象实际训练了 432 次 Adam 更新、5,280 个学生控制步。模仿训练示范只采集一次，弹簧/电机各用 432/360 个训练决策，包含离线验证/测试在内共 720/648 个专家决策；Python 专家源函数每个成功决策执行三次一致性核验，故对应 2,160/1,944 次实际执行。PGAC 拟合没有新增专家调用。原对象比较和时延测量另计。

## 复现

在仓库根目录运行。第一条实验命令准备旧基准的冻结输入和权重；本机已有完整旧基准时可以直接运行新的跟踪实验。建议为复现实验指定新的输出目录。新实验依次调用公开登记与采样、训练模仿、鉴定可微模型、`optimize_external_policy` 和 `evaluate_external_pgac` 等操作。数值驱动使用明确标记的测试确认，真实自然语言角色另行验收。

```powershell
$env:PYTHONPATH = 'src'
.\.venv\Scripts\python.exe -B scripts/bench_online_pgac.py all --root test-output/pgac-online-benchmark-v2
.\.venv\Scripts\python.exe -B scripts/bench_tracking_diagnosis.py --output test-output/previous-tracking-diagnosis.json
.\.venv\Scripts\python.exe -B scripts/bench_tracking_pgac.py all --root test-output/pgac-tracking-reproduction
```

每个对象的 `operations.json` 记录正式作业与产物；`preblind.json` 记录开盲前冻结时间和文件哈希。`results.json` 含每条工况的配对种子、动作、状态/输出等违例计数和峰值、原对象 J、物理 RMSE、时延以及独立进程复算结果。
