# 从 MPC 模仿到在线 PGAC 的闭环基准

主案例使用仓内 spring-damper 的连续方程、位移输出和 6 步 MPC 参数，第二案例使用 dc-motor 的连续方程、转速输出和原 MPC 参数。两例均将方程作精确零阶保持离散化，外部 Python 对象负责采集和最终评价，另行登记并通过数值与雅可比验证的 Torch 模型用于反传。专家每拍求解同一有限时域二次问题。无约束解可行时直接采用，否则显式求约束解。仓内状态和动作界保持原值，本基准额外声明每拍动作增量上限为控制幅值上限的 45%。

## 实验设计

12 条原有专家训练工况全部用于模仿。另有 8 条专家工况用于模仿验证和离线动作评价。模仿使用 32–32 两个 tanh 隐层，最多 280 轮并以验证损失早停。两例的独立动作 RMSE 分别为动作量程的 0.293% 和 0.441%，满足预设的 5% 基线质量门限。每个对象的三个 PGAC 对照均从该对象同一组实际模仿权重开始。

每组做 192 次 Adam 更新，每次最多 16 个起点、12 步预测。现有实现从静态专家轨迹逐轨抽行。配平组保留完整预测时域和起点参考，只调整方向和瞬态阶段的抽样分布。在线组每 4 轮用当前策略重新运行 8 条训练工况，累计 32 回合、1,152 个原对象控制步，混合专家和学生片段，片段在回合末尾自然截断。

| 共享专家采集成本 | 弹簧 | 电机 |
|---|---:|---:|
| 训练分区有效控制决策数 | 432 | 360 |
| 全采集有效控制决策数（含模仿验证、测试） | 720 | 648 |
| 训练分区对应的专家控制函数执行数 | 1,296 | 1,080 |
| 全采集对应的专家控制函数执行数 | 2,160 | 1,944 |

Python 专家适配器每拍执行三次控制函数，分别作首次计算、同实例确定性复算和新实例复算。上表按这个已执行的调用协议计数。每次控制函数求解凝聚二次问题，可行的无约束解直接返回，单独的 SLSQP 优化器触发次数未计数。PGAC 训练再调用 MPC 的次数均为零。原对象验收与计时所调用的专家不计入共享采集成本。

每个对象独立生成 8 条验证工况与 8 条盲测工况，覆盖正阶跃、负阶跃、跨零反转和中途接管，每族有干净与带噪的两条轨迹。所有控制器使用配对的外生序列和噪声。协议要求验证和盲测的均值 J 至少改善 0.5%，任一工况的 J 退化最多 5%，全程满足状态、输出、动作与动作变化率约束。候选权重均在第一次盲测前冻结。以下结论只覆盖本次每对象一个训练种子和上述有限工况。[预注册](protocol.json)

## 独立原对象结果

下表列的是候选本身的盲测表现。RMSE、动作 RMS 和动作增量 RMS 均先逐工况计算再等权平均。弹簧使用 m、N，电机使用 rad/s、V。计时为该次评价的控制器单次调用中位数，CPU 单线程、batch 1、4 次预热和 24 次测量。同结构神经网络的耗时差包含本机负载波动。

| 对象 | 控制器 | 综合 J | 跟踪 RMSE | 动作 RMS | 动作增量 RMS | 耗时 µs |
|---|---|---:|---:|---:|---:|---:|
| 弹簧 | MPC | 0.00334529 | 0.06754 | 0.7198 | 0.2414 | 82 |
| 弹簧 | 模仿 | 0.00335680 | 0.06814 | 0.7163 | 0.2227 | 374 |
| 弹簧 | 原 PGAC | 0.00315904 | 0.07189 | 0.6665 | 0.2060 | 299 |
| 弹簧 | 仅配平 | 0.00317228 | 0.07091 | 0.6744 | 0.2129 | 322 |
| 弹簧 | 在线 PGAC | **0.00315465** | 0.07201 | 0.6670 | 0.2180 | 267 |
| 电机 | MPC | 0.00714039 | 5.4920 | 5.7219 | 1.4831 | 102 |
| 电机 | 模仿 | 0.00712527 | 5.4756 | 5.7410 | 1.4579 | 312 |
| 电机 | 原 PGAC | **0.00697969** | 5.1251 | 6.3035 | 1.6564 | 369 |
| 电机 | 仅配平 | 0.00703640 | 5.2878 | 6.0670 | 1.6354 | 561 |
| 电机 | 在线 PGAC | 0.00714768 | 5.4123 | 5.9603 | 1.6856 | 436 |

**弹簧在线组交付候选。** 8 条测试轨迹的 J 分别改善 2.67%–7.59%，组均值较模仿下降 6.02%，较原 PGAC 再下降约 0.14%。力的 RMS 降低 6.89%，位置 RMSE 升高 5.68%。本次提升主要来自降低控制作用，轻量网络的 Python 推理耗时仍高于此案例的凝聚型 MPC。
**电机在线组保留模仿基线。** 原对象验证已选定模仿。盲测中在线候选相对模仿 J 升高 0.315%，最差工况升高 5.32%，跨零工况上则有改善。原 PGAC 和仅配平两组分别通过了其独立发布门，增益为 2.04% 和 1.25%。协议对各组独立验收，没有从盲测结果重新挑选训练超参数。

所有表内试验的盲测约束越界均为 0。每个发布版本均经新的隔离 Python 进程从独立包加载，使用原对象方程、各自反馈及冻结的噪声逐步复算。逐工况、逐种子指标、峰值、冻结权重和材料哈希见[完整证据](results.json)。

### 盲测后边界压力检查

单独加载上述已交付版本，在绑定的原对象上作无噪声、零外扰的正负镜像压力检查。每个对象检查 6 条轨迹，各 24 拍。这些轨迹是在盲测完成后设计的，独立于拟合、主消融和发布决定。

| 冻结的交付策略 | 接近状态边界的初始值 | 从高上一动作反向调节时的实测 |
|---|---|---|
| 弹簧在线 PGAC | 位移 ±0.94 m（上限绝对值 1 m），或速度 ±1.395 m/s（1.5 m/s） | 上一动作 ±3.8 N。两个方向各有 3 拍达到 Δu 上限 1.8 N/拍 |
| 电机模仿 | 转速 ±37.6 rad/s（40 rad/s），或电流 ±11.16 A（12 A） | 上一动作 ±22.8 V。两个方向各有 3 拍达到 Δu 上限 10.8 V/拍 |

两对象各完成 144 拍，状态、输出、执行动作和动作增量均保持在声明边界内。接近物理状态边界发生在初始时刻，随后向域内恢复。高上一动作取幅值上限的 95%，新的执行指令在全部检查中最高为 2.141 N 和 13.925 V，本次观测到的是**变化率限幅**。逐轨原始峰值、触限拍数、权重哈希见[压力检查记录](boundary-stress.json)。

```powershell
.\.venv\Scripts\python.exe -B scripts/bench_pgac_boundaries.py test-output/pgac-online-benchmark-v2 test-output/boundary-stress-replay.json
```

## 复现

在仓库根目录的 PowerShell 中运行以下命令。默认结果保存到 `test-output/pgac-online-benchmark-v2`，可通过 `--root` 指定新的空工作区。已存在的阶段会核验原请求后复用。一次新的独立复现实验应使用新目录。

```powershell
$env:PYTHONPATH = 'src'
$env:PYTHONUTF8 = '1'
.\.venv\Scripts\python.exe -B scripts/bench_online_pgac.py all --root test-output/pgac-online-rerun
```

驱动依次运行 `prepare`、`train`、`evaluate`、`summary`，或可按相同顺序分别运行。材料目录包含两个原生适配器、专家采集、可微对象、工况与优化设置。每个对象的 `operations.json` 指向真实公共操作回执及其产物。发布包在 `workspace/artifacts/<evaluate_online 的 artifact_id>/bundle`，根目录的 `frozen-candidates.json` 和 `frozen-inputs.json` 记录盲测前冻结的权重与输入。该驱动调用公共领域操作，并明确使用 test_fixture 作为数值基准确认来源。它本身不调用 LLM。

最终内核已用初次盲测前封存的配置和初始权重复训。两个对象各运行 1,152 个学生控制步、192 次更新，所得候选均与各自原候选的 6 个参数张量逐项相等，整个 `model.pt` 的 SHA-256 也一致（弹簧 `1d7365d6…dad60`，电机 `8dc82dcf…b23aa`）。

以下命令从上述完整运行导入模仿权重、预测模型与资格凭据，在两个新工作区分别执行一次 `optimize_external_policy`，校验冻结配置并逐张量比较两次候选。逐项证据输出到各自的 `repeat.json`。请使用尚未包含对应对象子目录的目的目录。

```powershell
.\.venv\Scripts\python.exe -B scripts/bench_pgac_repeat.py test-output/pgac-online-rerun test-output/pgac-online-repeat
```
