# 弹簧对象在线 PGAC 复核

使用已确认的可执行弹簧对象和 MPC，保留整轨划分与实际上一动作。先进行正式专家采集和模仿，固定模仿权重、归一化、力与力变化率边界。在确认对象、约束与代价对称后，通过正负成对阶跃、双向跨零和非零速度中途接管覆盖反向控制。训练池、验证和最终测试使用相互独立的具体初态、外生序列及噪声种子。

为每条验证轨迹列出代价差异。一次历史运行中，正向与负向工况的变化方向相反；建议检查每族跟踪项与超速峰值。相同确定性初态和外生输入换一个无效种子会重复同一闭环。若原对象内闭环效果未达到目标，分别检验场景配比和在线片段更新，两次试验复用同一模仿权重并统计专家求解、学生仿真和更新次数。

产品内通过轻量化角色执行 `optimize_external_policy` 并选择 `replay.mode=online`，通过 `prepare_handoff` 和 `evaluate_external_pgac` 进行原对象验收。对应的物理信号见[弹簧案例](README.md)，回放时序见[PGAC 方法](../../knowledge/pgac.md)。同目录原始报告和 runs/pgac 中的指标属于既有固定工况案例。

## 原对象独立盲测实绩

Harness 仓库中的 `examples/pgac-online/protocol.json` 在训练前冻结了两个对象、训练与留出种子、四个工况族和验收门限。每个对象 8 条验证、8 条盲测。工程要求为等权综合代价 J 至少改善 0.5%，每条工况最多退化 5%，状态、输出、动作和变化率均可行。以下数值是一个训练种子在这组工况上的实测。

| 正式训练组 | 弹簧盲测 J | 电机盲测 J |
|---|---:|---:|
| MPC 专家 | 0.00334529 | 0.00714039 |
| 模仿基线 | 0.00335680 | 0.00712527 |
| 原 PGAC | 0.00315904 | 0.00697969 |
| 仅配平专家起点 | 0.00317228 | 0.00703640 |
| 在线 PGAC 候选 | 0.00315465 | 0.00714768 |

弹簧的在线候选通过发布门，J 比模仿降低 6.02%，较原 PGAC 再降低约 0.14%。力 RMS 降低 6.89%，位置跟踪 RMSE 升高 5.68%。电机的在线流程在原对象验证即选择保留模仿，在线候选盲测 J 增加 0.315%，最差工况增加 5.32%。两例表内各策略在盲测均无约束违例。

每组微调 192 次，复用同一对象的专家数据与模仿权重。弹簧和电机的训练分区分别含 432、360 次有效控制决策，全专家采集分别为 720、648 次。Python 适配器每拍首次计算后作两次独立性检查，因此训练分区对应 1,296、1,080 次专家控制函数执行，包含模仿验证与测试的整个采集对应 2,160、1,944 次。可行的无约束二次解直接返回，SLSQP 求解器调用次数未单独统计。在线组各增加 1,152 个学生原对象控制步，额外 MPC 训练调用均为零。完整复现命令、逐工况指标和部署复算结果见 Harness 仓库 `examples/pgac-online/README.md`、`examples/pgac-online/results.json` 及 `scripts/bench_online_pgac.py`。

以跟踪为优先目标的新任务，可对照以上历史 J 实验，拆开位移误差、力及力增量来解释同一次权重更新。用新冻结的轨迹、相同模仿权重、指定物理输出的 RMSE、动作和增量开销上限重新验收。完整可复现协议和实验数据位于 Harness 仓库 examples/pgac-tracking/。

跟踪优先的复验分别用 24 条全新盲测轨迹验收弹簧和直流电机。协议要求平均物理 RMSE 至少改善 1%、最差单条最多退化 5%、相对模仿动作 RMS 最多增加 15%、每拍增量 RMS 最多增加 25%，并满足零越界。这些是本次实验的工程预算。

| 对象与主输出 | 模仿 → PGAC 的盲测 RMSE | 动作 RMS 变化 | 增量 RMS 变化 |
|---|---:|---:|---:|
| 弹簧位移 | 0.080580 → 0.076728 m，改善 4.78% | +4.70% | +18.74% |
| 电机角速度 | 6.383865 → 5.633642 rad/s，改善 11.75% | +13.91% | +6.06% |

两例各 24 条轨迹的跟踪 RMSE 全部改善，动作预算及硬约束通过。弹簧的原二次 J 增加 1.59%，与力和力增量增加同时发生。验收应按训练前选择的主输出、动作预算、最差工况及原对象测试给出结论。冻结候选、逐工况指标、原对象轨迹独立复算与复现命令见 Harness 的 `examples/pgac-tracking/README.md` 和 `examples/pgac-tracking/results.json`。
