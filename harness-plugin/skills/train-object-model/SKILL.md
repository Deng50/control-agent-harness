# 对象模型自动化训练

用 `control_library_search` 查询实际材料和要预测的量。例如 CSV 整轨划分对应 `audit-train-tabular-model`，带状态方程的逐拍预测可查看 `fit-state-flow`，辨识物理参数可查看 `identify-greybox-parameters`。用原生 `skill` 加载选中的技能，再按搜索结果读取案例的信号约定、训练代码和分工况误差。将采样周期、输入保持方式和可观测量与本次对象逐项对齐。

先确定用户要交付的是接口分析、数据、网络还是残差校正模型，以及希望在哪一步结束。普通模式给有依据的推荐；专家模式使用用户参数，两者共用同一生效配置。

用户指定独立训练及预测接口时，将拟合代码维护在交付脚本中，保存能被预测入口直接加载的模型。用该接口从初态重放整条留出轨迹，核对步首或步末、单位和状态顺序。减少误差的实验沿用可重建的训练入口，保留当前可运行版本。需要登记模型或发起领域作业时，可查 [执行与确认](../references/execution.md) 和 `control_help` 中该操作的要求。

用户要求把采样对象交给 MPC 时，先用 `prepare_handoff` 选择同一原对象的完整采样数据。用 `convert_plant_predictor` 核对已登记的显式方程，或在状态、输出映射和独立激励充分时辨识有界仿射模型。解释模型逐通道单步和整轨误差、验证过的工况及来源版本。用户只要求采样或训练导出时，在该阶段交付。

## 按材料选择路线

用户上传 Python 对象并要求生成可仿真的 SLX 时，按[从 Python 转换 Simulink](../references/execution.md#从-python-转换-simulink)执行。共享文件位于本技能目录的上一级 `skills/references/execution.md`。读取当前附件后，使用 `control_replay_plant_source` 回放原始函数，再把工具返回的参考文件交给 `control_build_zoh_plant`。交付点是可重载的对象模型和对照结果。

- 有 Python、MATLAB 或 Simulink 对象：读 [材料与信号](../references/materials.md)，提出状态、输入、输出、扰动、单位、采样与复位方式。静态读取不能充当运行证据。完成接口核对后，按 [采样](../references/sampling.md) 提交用户工况或推荐工况摘要，确认后再运行。
- 只有 CSV/XLSX 数据：确认工作表、列位置、输入输出和时间/行程语义；直接规划数据网络，不要求用户补交 nominal model。动态预测明确历史窗口或下一时刻标签，不能把仅有 I/O 的回归网络宣称为完整物理状态模型。
- 有名义模型及对齐数据：可选择机理加残差；检查残差的状态/导数单位与实际组合方式。

## 训练与交付

准备训练时读 [网络与物理训练](../references/training.md)。推荐或接收网络类型、变量选择、层数/宽度、学习率、batch、epochs、早停和划分，展示实际摘要后确认。选 PINN 时要求可信方程、变量/参数映射和真实物理损失；仿真来源、L2或输出裁剪不构成PINN。

按 [评价与报告](../references/evaluation.md) 对独立数据给出逐输出指标。有物理模型时同工况比较；没有时标记不适用。交付权重、预处理、变量顺序、单位、窗口、实际配置、推理样例及报告。用户仅要求网络时在导出后结束；后续MPC设计是另一个可选任务。

## 条件 ODE PINN

先查 `control_help({operation:'prepare_pinn_problem'})`。当前已实现的模板为热过程 `C*dT/dt=-G*(T-Ta)+P`，每条轨迹的功率恒定。明确 C[J/K]、G[W/K]、Ta[K]、时间/初温/功率范围、单位、整工况划分，以及不可变材料中的参考 CSV 和训练配点 CSV；成员路径相对于材料产物根目录，通常以 `source/` 开头。只有数据但缺可信方程时使用普通 NN，不编造物理损失或擅自套用热过程。

`prepare_pinn_problem` 在一次 signals 摘要中确认完整声明后，只准备与核验数据，不执行源码或训练。`train_pinn` 再确认已解析方程/信号/归一化及网络、数据/物理/初值权重等训练摘要。输入是时间、初始温度和恒定功率，输出是该条件下的温度轨迹；网络输入维度不等于物理状态维度。时间求导保留归一化链式系数，方程残差用 W、初值用 K 的声明尺度无量纲化。

配点只覆盖训练条件；验证集选择权重，测试集最终评价。至少报告分项损失、实际参数梯度贡献、物理模型参考对比、逐工况预测误差、方程残差和最大初值误差。条件覆盖不足时如实说明，不能凭声明的范围声称已完成泛化验证。关闭物理项必须显式 `ablation:true`，只交付标明 physics-off 的非激活对照，不能冒称 PINN 或替换有效物理网络。

独立包支持有界 `T(t;T0,P)` 查询，并明确每个 P 表示从初始时刻起整条轨迹的恒定驱动。它没有通过任意状态转移接口验证；交付后结束，不自动送入 MPC/PGAC，也不把 successive queries 当作时变输入闭环。
