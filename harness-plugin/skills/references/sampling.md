# 工况与采样

由模型性质、任务和用户边界选择阶跃、扫频、有界激励或用户时序，给出推荐理由。确定性程序生成实际信号，检查幅值、变化率、耦合约束、初值、dt、时长、轨迹数和状态域；随机数据不自动代表充分激励。

专家工况核对时间、单位和边界；普通模式展示推荐摘要。确认版本内可先小试跑再批采，失败、发散和求解状态保留。未经确认不开始试跑或采样，改变关键范围后更新摘要。

每条轨迹记录reset、初始记忆、输入/参考/扰动和来源。划分独立工况与行程，避免同一轨迹随机拆行泄漏。已采实车数据不增加虚假的采样步骤；只有一个可执行Plant也可以规划采样，不强制配两个模型。

受支持单对象入口使用 `register_material` → `register_plant` → `recommend_sampling` → 确认摘要 → `sample_model`。始终先查 `control_help` 的具体 schema。`config.trial` 声明固定前缀，`sampling_run` 选择 trial/full，两者可共用已覆盖完整范围的同版本确认。试跑不是训练数据。MATLAB 函数与声明端口/状态映射的 SLX 走一次本地 MCP 批处理；SLX 运行边界在每轨仿真返回后检测，不能宣称在线实时保护。采样支持不等于任意模型可用于 MPC 预测或可微训练。

MATLAB对象和专家可在同一本地脚本完成整批闭环，LLM负责准备和解释结果。每步LLM/MCP往返不承担实时控制循环。MCP超时不能证明外部计算停止，确认资源状态后再提交后续任务。

在线 PGAC 将专家示范和学生闭环经验分别记账。每条训练工况注明族、初态、上一实际动作、控制步数、参考、扰动及有效噪声。按整条工况冻结训练、验证和盲测分区。比较正负阶跃、反转、中途接管和接近边界片段，记录各族有效场景数和权重。对确定性任务，换一个未使用的噪声种子不会增加覆盖。只有对象、约束和目标满足相应对称性时才生成镜像工况。验证和盲测使用独立的具体序列。

复验曾用于分析的对象时，给训练、开发验证和盲测另建冻结的初态、参考与扰动序列和有效噪声。检查相对于旧实验、当前示范及其他分区的物理重复。训练可用正负配对、反转、中途接管和贴近限幅的工况；对称操作需先核实对象、约束及接口支持。验证与盲测让三个控制器用同一组物理初态及各自的状态反馈。
