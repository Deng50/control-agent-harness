# 材料与信号

路径必须对执行主机可见；上传与路径应进入同一材料登记。保留原件、来源、哈希及依赖。MATLAB工程可能需要初始化脚本、引用模型、数据字典和工具箱；缺项给清单，不悄悄换成另一对象。

当前用 `inspect_material` 查看原件清单，用 `register_material` 固化来源与依赖。原生上传通过 `/control-upload` 得到主机路径及原文件名，再调用同一个登记操作并标记 `source_kind:upload`；不要把上传缓存名当作原始格式。登记只证明字节及来源，不证明模型能运行。

源码、函数参数及SLX端口只提供结构线索。分别确认状态x、控制命令、实际执行量、输出y、扰动d、参考r，记录nx/nu/ny、单位、正负、dt、时延及reset/隐藏状态。特征宽度不一定等于状态维度，输出也不一定是全部状态。

CSV/XLSX记录工作表、列位置、时间轴及车辆/行程分组。电流充放电符号、单体/整包电压、请求/实际功率、事后SOC等不能按列名或相关性确定因果角色。历史窗口和下一时刻标签必须明确，未来输出不能成为部署策略的当前输入。

用 `inspect_table` 保留同名表头的位置。数据接口为 `tabular_supervised`，列记录 `index/header/worksheet`，信号记录角色、单位、可观测性与可用性延迟，特征记录窗口和 lag，目标记录 offset；`input_dim/output_dim` 来自这些定义，不能冒充被控对象的 nx/nu/ny。静态回归使用同一行；动态预测需明确秒制时间列和 sample_time。`prepare_supervised_dataset` 在确认后按行程/时间先划分再建窗口，Scaler 只拟合训练集；该操作本身不训练网络。

MATLAB/Simulink交互可用已启用的官方MCP和专业skills。先查真实工具与产品依赖，结构读取、执行、预测器获取和可微性分开证明。未加载MCP或适配器时不声称已经仿真；Engine API仅在实际跨语言程序需要时采用，不把安装源码当作Python包已可用。
